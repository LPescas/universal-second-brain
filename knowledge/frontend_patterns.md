# Padrões Frontend — Base de Conhecimento

> Carregamento sob demanda. Triggers: html, css, js, react, next, ui, design.

---

## Preferências de Design (Validadas)
- Dark mode como padrão
- Glassmorphism para elementos de destaque
- Micro-animações para UX premium
- **PROIBIDO**: Violet/Purple (regra do frontend-specialist)
- Paletas curadas (HSL), sem cores genéricas
- Tipografia moderna (Google Fonts: Inter, Roboto, Outfit)
- Gradientes suaves

## CSS
- Vanilla CSS primeiro (Tailwind apenas se solicitado)
- BEM quando vanilla
- Responsivo como padrão

## JavaScript
- `const` > `let` > nunca `var`
- Semicolons obrigatórios
- Single quotes
- Framework preference: React/Next.js para projetos complexos

## i18n
- Suporte obrigatório: PT-BR + EN
- Language switcher no frontend
- Dados internos em inglês, interface em PT-BR

## Templates Flask (Projetos UNIQ)
- HTML com Jinja2
- Assets organizados por módulo: `<modulo>/assets/`
- Templates organizados por módulo: `<modulo>/templates/`
